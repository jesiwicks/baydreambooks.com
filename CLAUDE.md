## WHAT THE SITE IS
The storefront and library for Baydream Books: Bionic Lettering editions of public domain classics, sold through Amazon KDP in paperback and hardback. Readers include homeschool parents, teachers, book clubs, and readers with ADHD, dyslexia or reading fatigue. Accessibility is a core requirement, not a nice-to-have.

---

## SITE STRUCTURE
- **Home page** (`/`): header search, hero, Shop by grade tiles (K-2, 3-5, 6-8, 9-12), A-Z title browse, New and featured row, About Bionic Lettering, About Baydream Books. Search, grade and A-Z results show in place on the home page. There is no separate library or search page.
- **Book entry pages** (`/books/<slug>/`): one per row of the production sheet, generated by the build.

---

## DATA SOURCE: PRODUCTION GOOGLE SHEET
Each row = one book entry page. Fields:
Title, Author, Summary, Description, Word count, Page count, Grade level (1-12), Genre, Country of origin, Year published, Keywords, Link to hardback on AMZ, Link to paperback on AMZ.

- Grade level (1-12) maps to the home page bands: K-2, 3-5, 6-8, 9-12
- "More by [Author]" on each book page is built from rows with the same Author; if the author has one title, show "More books" instead
- Never invent book data. If a field is empty, leave it off the page.

---

## COVERS
- Files live in `src/covers/`, named `TitleAuthor-CardImage.png` (example: `PrideAndPrejudice-JaneAusten-CardImage.png`)
- Name rule: TitleCase words, no spaces, punctuation dropped ("L. Frank Baum" -> `LFrankBaum`), leading "The"/"A" kept
- Covers are Jesi's own Midjourney art. Never pull images from Amazon.
- Rows with no matching cover get a plain title card and are listed in the build output

## READING THEMES AND BIONIC TOGGLE
- Three skins: Light (default), Dark, Dyslexic. One Bionic Lettering toggle that works in any skin.
- Light: bg #FBF8F2, text #2B2A28, muted #5A564F, accent #A8492F, focus #1F4E79
- Dark: bg #121212, text #E8E6E1, muted #A3A19B, accent #E8927A, focus #9CC3F0 (never pure white on pure black)
- Dyslexic: bg #FAF3E3, text #262522, muted #55514A, accent #9E4429; Atkinson Hyperlegible, 19px body, line-height 1.8, letter-spacing 0.04em, word-spacing 0.16em, no all-caps labels, no sideways carousels
- Bionic toggle uses the same text-vide approach as the book pipeline, applied to body copy

## ACCESSIBILITY - EVERY FILE
- WCAG 2.2 AA minimum: text contrast 4.5:1 in every skin, check new colors before using them
- Visible keyboard focus on every interactive element
- Touch targets 44px minimum
- Real `<button type="button">`, `<a href>`, `<input>` + `<label>`; no clickable divs
- Skip link on every page
- Scrollable rows must be keyboard reachable (`tabindex="0"`, labelled)
- A-Z letters with no titles are shown but disabled and announced as "no titles"

---

## ABSOLUTE RULES - APPLY TO EVERY FILE YOU TOUCH
- **No em dashes** anywhere in site copy - use hyphen (-) or rewrite
- **No periods at end of titles or headlines**
- **Dividers use slash (/)**, not pipe or hyphen
- `<!DOCTYPE html>` at top of every file
- All buttons must have `type="button"`
- No Google Fonts or any external font CDN - fonts are self-hosted from `/fonts/` via `/fonts/fonts.css`
- Never write marketing copy or claims - all copy comes from Jesi or her boilerplate
- **Public domain source text is never edited.** Jesi's style rules (em dashes etc.) do NOT apply to quoted Gutenberg text; it stays verbatim
- Never delete a file and re-add it - always edit in place

## DEPLOYMENT PROCESS
1. Edits are made in a working copy via Claude Code
2. Commit and push to `jesiwicks/baydreambooks.com` main branch
3. Cloudflare Workers Builds runs `npm run build` (writes `dist/`) then `npx wrangler deploy`
4. `wrangler.toml` serves `./dist/` with `not_found_handling = "404-page"` and `html_handling = "auto-trailing-slash"`

Workflow rules: chat reviews Claude Code's proposals, Claude Code executes. Stop before every push, commit or deploy and wait for Jesi's explicit "yes" or "go". Commits carry the Claude co-author line. Large HTML edits go through bash without loading the whole file into context, to avoid truncated commits.

---

## CACHING
`src/_headers` is copied from jesiwicks.com: fonts 1 year immutable, images and `/covers/*` 30 days, HTML revalidates in the browser with a 1-hour edge cache and stale-while-revalidate.
